# virt-manager.org

Source URL: https://virt-manager.org (fetched 2026-11-26)

- Desktop UI to manage VMs through libvirt. Mainly KVM; also Xen and LXC.
- Shows domain summary with live stats; wizards for creating/editing domains and hardware.
- Embedded VNC and SPICE client for guest console.
- Supporting tools: virt-install, virt-viewer, virt-clone, virt-xml, virt-bootstrap.
- Site content licence: CC BY-SA 4.0 (contributors 2009-2024). Software licence not stated on page.
- Install listed: Fedora (yum), Debian (apt-get), Gentoo (emerge), OpenBSD (pkg_add); source release; git clone https://github.com/virt-manager/virt-manager.git
