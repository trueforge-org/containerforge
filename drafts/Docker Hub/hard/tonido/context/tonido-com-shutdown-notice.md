# tonido.com (shutdown notice)

Source URL: https://www.tonido.com (fetched 2026-11-26)

- Page is a shutdown notice from the Tonido Team covering 2008-2022. Tonido is ending.
- Products mentioned: TonidoPlug (NAS "cloud-in-a-plug"); Tonido later evolved into FileCloud.
- Software and web access should keep working on a local network (per page).
- Suggested replacement: FileCloud Community Edition (filecloud.com/filecloud-community-edition/); installation guide at filecloud.com/supportdocs/fcdoc/latest/server/filecloud-server-administrator-guide/installing-filecloud-server/installation.
- No Tonido-specific Linux or Docker download links on the page.
