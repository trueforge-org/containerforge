# luigi311/tanoshi README (summary)

Source URL: https://raw.githubusercontent.com/luigi311/tanoshi/main/README.md (fetched 2026-11-26)

## What it is
- Self-hosted web manga reader; also a Tauri desktop app (single device).
- Web reader is a PWA. Multi-user with admin / non-admin roles.
- Periodic chapter updates, optional auto chapter download.
- Notifications: Telegram, Pushover, Gotify. Tracking: MyAnimeList, AniList.

## Install / download
- GitHub releases (luigi311/tanoshi) or Docker Hub `luigi311/tanoshi`.
- Desktop: Windows `.msi`, Linux `.deb` / `.AppImage`, macOS `.dmg`.
