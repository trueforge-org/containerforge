# IPMI-Fan-Controller README

Source URL(s): https://raw.githubusercontent.com/EdwardChamberlain/IPMI-Fan-Controller/main/README.md. Fetched 2026-11-26.

## What it is
- Container with web GUI to manage fan speeds on Dell servers via IPMI.
- Prereq: IPMI enabled in iDRAC.
- Credentials: env vars OR typed into web GUI at runtime (env var names not in README).
- Roadmap: more features, multiple servers.
- README has no config file, ports, volumes, or run instructions.
