# xbmc/xbmc (upstream Kodi repo)

Source URL(s): https://github.com/xbmc/xbmc. Fetched 2026-11-26.

- Kodi: free/open source media player, GPLv2, mainly C++, add-ons mostly Python/XML.
- Build system: CMake. Build instructions per OS in docs/README.md (not fetched).
- Platforms: Android, Linux, BSD, macOS, iOS, tvOS, Windows.
- Version/release naming not stated on page; version.txt in repo (contents not shown). Downloads on kodi.tv.
- Source tarball used by linuxserver: `archive/${KODI_VER}-${KODI_NAME}.tar.gz` (e.g. 18.5-Leia).
