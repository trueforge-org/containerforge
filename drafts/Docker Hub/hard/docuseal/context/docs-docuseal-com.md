## What it is
- DocuSeal: open source platform for PDF forms, sending and collecting e-signatures. Offered as a hosted cloud service and as software you run yourself; positions itself as an alternative to DocuSign and PandaDoc.
- Self-hosting: "Host it yourself" link and an on-premises option. Docker not named on the page.
