# plausible/analytics README (master)

Source URL: https://raw.githubusercontent.com/plausible/analytics/master/README.md (fetched)

- What: privacy-first, cookie-free web analytics; Google Analytics alternative; cloud or self-hosted Community Edition (CE).
- License: CE AGPLv3 or later. JS tracker MIT. Plausible name/logo are trademarks of Plausible Insights OU.
- Stack: Elixir/Phoenix backend; PostgreSQL (general data) + ClickHouse (analytics); React + Tailwind frontend. Versions not stated.
- Self-hosting: CE install via github.com/plausible/community-edition (per page). CE community supported; releases twice/year.
- CE lacks: funnels, ecommerce revenue goals, SSO, sites API, Data Studio connector. Basic bot filtering.
- Docs: plausible.io/docs; API docs (events, stats, export).
