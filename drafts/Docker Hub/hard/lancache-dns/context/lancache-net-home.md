# lancache.net (home)

Source URL(s): https://lancache.net. Fetched 2026-11-26.

- LanCache.NET: game content caching for LAN parties (UKLans). MIT.
- Containers: monolithic (all-in-one), lancache-dns (DNS for cache controller), sniproxy, generic.
- Quick start: shallow clone docker-compose repo, edit `.env`, `docker compose up -d`.
- Router must use only lancache-dns for DNS. No deprecation notice.
