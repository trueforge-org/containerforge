## What it is
- Open-source ambient/bias lighting. Supports many LED devices and video grabbers. Built for low CPU load on SoCs (e.g. Raspberry Pi).
- Interfaces: JSON API, CLI, multi-language web UI. Python-scriptable effects engine, 39 built-in effects.
