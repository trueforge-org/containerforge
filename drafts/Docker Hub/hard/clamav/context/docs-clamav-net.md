## Facts
- Installation chapter: `manual/Installing.html`. Community projects: `manual/Installing/Community-projects.html`. Docker: `manual/Installing/Docker.html` (RAM section `#memory-ram-requirements`). Malware/FP FAQ: `faq/faq-malware-fp-reports.html`.
- Updater: "advanced database updater" with scripted updates, digital signatures and DNS-based version queries. Signed databases mean only trusted definitions run.
- Requirements (baseline): **3 GiB+ RAM**, one 2.0 GHz+ CPU, **5 GiB free disk**. Docker guidance: plan for roughly **3-4 GiB RAM** (less may work with limitations).
- Malware samples: https://www.clamav.net/reports/malware; false positives: https://www.clamav.net/reports/fp.
- Config pages (clamd.conf, freshclam.conf) and mirror details are not linked from this landing page.
