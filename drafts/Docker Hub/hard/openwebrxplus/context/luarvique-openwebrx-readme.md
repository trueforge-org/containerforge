# luarvique/openwebrx (OpenWebRX+) README

Source URL(s): https://github.com/luarvique/openwebrx (raw master README) · fetched 2026-11-26

- OpenWebRX+ = improved OpenWebRX multi-user web SDR receiver; many decoders (AIS, SSTV, FAX, FLEX, HFDL, VDL2, ADS-B, ACARS, etc.).
- Features: chat, recorder, bookmark scanner, admin tools, touchscreen.
- License: original OpenWebRX is AGPL v3; commercial license offered. No separate license stated for the + fork (page).
- Install: pre-built packages from PPA-style repo (luarvique.github.io/ppa); disk images on GitHub Releases.
- Default port, config paths, Python version: not stated.
- Backend components: csdr, digiham, wsjt-x, direwolf, JS8Call, m17-cxx-demod.
- Docs: fms.komkon.org/OWRX (draft).
