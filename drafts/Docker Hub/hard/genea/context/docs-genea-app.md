# genea.app (project website)

Source URL(s) + fetch date:
- https://www.genea.app/ (2026-11-26, WebFetch summary)

What it is: family tree editor, "privacy by design", open source, free. GEDCOM based, so trees can move to MyHeritage, FamilySearch, Ancestry.

Delivery:
- Hosted web app at genea.app (mobile and desktop browsers). Client-side processing only; changes kept on the user's device.
- Trees can be downloaded as GEDCOM and moved by e-mail or cloud storage.
- Git integration: load/save to GitHub, GitLab, Gitea, Gogs or GitBucket (repo URL, branch, personal access token, optional CORS proxy).
- Self-hosting is not described on the page; the source is on GitHub.
- Android app on Google Play (per README).
