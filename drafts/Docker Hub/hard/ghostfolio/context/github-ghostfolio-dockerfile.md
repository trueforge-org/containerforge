## What it is
Multi-stage Node build of the Ghostfolio API/app (AGPL-3.0). Build runs `npm run build:production`.

## Stages
| Stage | Base | Notes |
| --- | --- | --- |
| builder | `--platform=$BUILDPLATFORM node:22-slim` | build tools, `npm ci`, `npm run build:production` |
| runtime (unnamed) | `node:22-slim` | copies `dist/apps` only |

## Build steps and deps
- Builder apt: `g++ git make openssl python3`
- Builder: `npm ci` in `/ghostfolio`, then `NX_DAEMON=false`, `npm run build:production`
- Builder: second `npm ci` in `/ghostfolio/dist/apps/api` using the original `package-lock.json`
- Builder: `npm run database:generate-typings` (Prisma typings; Prisma version comes from lockfile, not pinned in Dockerfile)
- Runtime apt: `curl openssl`

## Runtime
| Item | Value |
| --- | --- |
| ENV | `NODE_ENV=production` |
| WORKDIR | `/ghostfolio/apps/api` |
| Copied app | `/ghostfolio/apps/` (from builder `dist/apps`, chown node:node) |
| Entrypoint script | `/ghostfolio/entrypoint.sh` (from `docker/entrypoint.sh`, chown node:node) |
| CMD | `["/ghostfolio/entrypoint.sh"]` (no ENTRYPOINT) |
| USER | `node` |

## Ports

## Volumes/paths
- No VOLUME instruction.

## User/UID
- `node` (image default node user).

## Healthcheck
- None in Dockerfile.

## Version/asset naming
- Base: node 22 (slim). No ARG declared.
- Label: `org.opencontainers.image.source=https://github.com/ghostfolio/ghostfolio`

## Gotchas
- `package.json` is regenerated by the build; the Dockerfile copies the original back over it before typings generation so scripts are present.
- `npm ci` runs twice (root and `dist/apps/api`); both need the lockfile.
- Build stage needs g++/make/python3 (native modules).
