# MediaElch docs: about

**Source:** https://mediaelch.github.io/mediaelch-doc/about.html (fetched 2026-11-26; docs for 2.12.0)

## What it is
- "MediaManager for Kodi": movies, TV shows, concerts, music; NFO files; fanart from fanart.tv.
- Scrapers: TMDb (20+ languages), Videobuster, TVMaze, fernsehserien.de, IMDb, fanart.tv, plus some adult-content scrapers.
- Music: TheAudioDB, AllMusic, Discogs. TV themes and trailers downloadable.

## Features (navigation)
- Movie, TV Show, Concert, Music, Settings sections; library export, Renamer, Kodi sync, Portable Mode.
