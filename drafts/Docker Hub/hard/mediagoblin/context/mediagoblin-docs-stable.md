# MediaGoblin docs (stable): overview

**Source:** https://docs.mediagoblin.org/en/stable (fetched 2026-11-26; docs built 2026-03-05)

## What it is
- Free-software media sharing platform (photos, video, other media).
- Docs CC0. Site admin guide chapters include Deploying, MediaGoblin in Docker, Configuring, Upgrading, Media Types.
- Pump API: work in progress; no full federation; media upload works.
