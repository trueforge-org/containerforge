# Difegue/LANraragi README (dev branch)

Source URL(s): https://raw.githubusercontent.com/Difegue/LANraragi/dev/README.md (repo: https://github.com/Difegue/LANraragi). Fetched 2026-11-26.

- Open source server for archival of comics/manga. Mojolicious + Redis (Dockerfile uses valkey).
- Formats: zip, rar, targz, lzma, 7z, xz, cbz, cbr, cbw, pdf; epub barebones.
- OPDS catalog with PSE. Client API. UI localized in 11 languages (Weblate).
- Distribution: Docker Hub `difegue/lanraragi`, GitHub Releases, Homebrew `lanraragi`, Windows nightly via nightly.link.
- Docs: GitBook (sugoi.gitbook.io/lanraragi, dev). Docker run/env details NOT in README.
