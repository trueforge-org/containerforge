## What it is
- Music tagger: identifies music, repairs metadata, upgrades artwork, finds duplicates, organizes files.
- Matches via MusicBrainz, Discogs, AcoustID, Bandcamp.
- Desktop (macOS, Windows); Linux/NAS/Docker via remote browser interface.
