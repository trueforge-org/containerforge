## What it is
- ROOT: data storage, processing and analysis framework (histograms, fitting, RDataFrame, columnar storage). C++ with Cling interpreter; Python bindings via cppyy.
- License badge: LGPL v2.1+ (supports LGPL-2.1-or-later).
