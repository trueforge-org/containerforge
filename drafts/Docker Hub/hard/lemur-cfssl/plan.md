## 7. start.sh
- First run: generate secrets (`openssl rand`) into `/config/lemur.conf.py` (umask 077) only when the file is missing; never log secrets.
- DB URI from env is applied on every start by rewriting only the generated override file `/tmp/lemur.env.py`, which the main config imports.
- CFSSL: seed `/config/cfssl/{ca-config.json,ca-csr.json}` from defaults when missing; generate CA with `cfssl genkey -initca` / `cfssljson -bare ca` only when `/config/cfssl/ca.pem` is missing; keys mode 0600.
- Run schema migration idempotently: `lemur db upgrade -d <migrations dir>` (UNVERIFIED command) after waiting for PostgreSQL to accept connections with a bounded retry. Admin user creation is manual (draft caveat) or via `lemur create_user` when `LEMUR_ADMIN_PASSWORD` is set (UNVERIFIED).
- Start CFSSL in the background: `cfssl serve -address 0.0.0.0 -port 8888 -ca /config/cfssl/ca.pem -ca-key /config/cfssl/ca-key.pem -config /config/cfssl/ca-config.json &` (flags from CFSSL docs; UNVERIFIED here). Trap signals.
- `exec lemur start -b 0.0.0.0:8000` (UNVERIFIED CLI form; Lemur uses gunicorn via `lemur start`).

## 9. Rootless and read-only-rootfs adaptations
- Upstream (halianelf) runs as root with `/data` and `/config`. Ours: `USER apps`; CA and Lemur config live in `/config` (single persistence; `/data` is dropped).
- Write paths: `/config` (config, CA keys), `/tmp` (gunicorn temp, pid, pip caches, `LEMUR` log dir if any: UNVERIFIED). Lemur logs to stdout by config.
- CFSSL ports are above 1024: no capabilities needed.

## 10. Risks, caveats and open questions
- Python version mismatch with Lemur (see section 3).
- No upstream Dockerfile to copy; two-process container without a supervisor (start.sh manages CFSSL in background; if CFSSL dies Lemur keeps running unless monitored: use `wait -n`).
- PostgreSQL is mandatory; Celery/Redis usage not verified.
- CA private key sits in `/config`; losing it loses the CA (draft caveat). Document the backup need.
- First admin user is manual.
- CFSSL API on 8888 is unauthenticated by default; recommend not exposing it publicly.
