Source: https://raw.githubusercontent.com/tsightler/ring-mqtt/master/README.md (repo https://github.com/tsightler/ring-mqtt), fetched 2026-11-26

## What it is
- Bridge between Ring cloud API (same as Ring apps) and a local MQTT broker; RTSP gateway for video streaming.
- Works with Home Assistant MQTT discovery and any MQTT tool.

## Install / config
- Points to the GitHub wiki for install methods and config options (wiki not retrievable, see README failures).
- Discussions for support; Issues restricted to collaborators.

## Important notes
- Cloud-only: no local control of Ring devices.
- Ring Protect subscription not required technically, but many features need it.
