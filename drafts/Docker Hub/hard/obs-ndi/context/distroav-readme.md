# DistroAV README (formerly obs-ndi)

Source URL(s): https://github.com/DistroAV/DistroAV (raw README) · fetched 2026-11-26

- What: OBS Studio plugin for NDI audio/video over network. Parts: NDI Source (receive), NDI Output (send program feed), NDI Filter / Dedicated Output (one source or scene).
- OBS Studio: 31.1.1 or higher, Qt6 build. Platforms: x64, ARM64, Apple Silicon.
- Runtime: NDI Runtime 6.3 or higher (proprietary, not in deb).
- License: not named in README (LICENSE file linked; plan reads GPL-2.0 from LICENSE file).
- Build deps: not in README (see wiki Development and CONTRIBUTING.md).
