## What it is
- Self-hosted image sharing platform. Symfony (PHP API) + SvelteKit (client). License AGPLv3 (per Docker Hub page).
- Storage providers: local, SMB, AWS S3.
- Auth: email/password, SSO/OIDC (Google, Authentik, Keycloak, Authelia, Pocket ID, custom OIDC).
- Upload formats: PNG JPG WEBP SVG BMP ICO GIF AVIF HEIC* TIFF*.
