# openaudible.org (home)

Source URL(s): https://openaudible.org · fetched 2026-11-26

- Audiobook manager: downloads Audible books, converts to M4B/MP3; built-in player, tag editor, transcription (local), password-protected web server.
- Unaffiliated with Audible. Personal backup use.
- License: shareware; free to try; one-time license (no subscription). Demo limits: conversion/split/join disabled; exports capped at 10 books. One license covers up to 5 accounts. One year of updates included.
- Platforms: macOS 10.12+ (universal), Windows 10 1607+/11 (x64, ARM64), Linux x64. Docker: experimental, not recommended for normal use.
- Linux installs: .sh (recommended), .deb, .rpm, AppImage; `wget -qO- https://openaudible.org/latest/OpenAudible_x86_64.sh | sh -s -- -q`.
- Linux needs libwebkit2gtk-4.1-0 (built-in browser for login).
- Version shown: 5.3.
