## What it is
- Finds space waste and broken files: duplicates (files and dirs), non-stripped binaries, broken symlinks, empty files/dirs, files with broken uid/gid.
- Output formats, paranoia mode, caching/replay, BTRFS support, non-interactive.
- Runs on Linux (main target), FreeBSD, Darwin, Solaris.
- License badge: GPLv3.

## Install
- Packages exist in distros (Repology); docs: installation page (see readthedocs file).
- Source install documented at rmlint.readthedocs.org/en/latest/install.html.
