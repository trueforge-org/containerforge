## 4. Dockerfile

1. `ARG VERSION`, `ARG TARGETARCH`, `USER root`.
2. `apt-get install -y --no-install-recommends php8.5-cli php8.5-fpm php8.5-ldap php8.5-xml php8.5-mbstring php8.5-curl php8.5-zip php8.5-memcached nginx composer unzip` (package names mirror bookstack; UNVERIFIED which are strictly needed). Not pinned: PHP is not the app version.
3. `mkdir -p /app/www`; `curl -fL -o /tmp/pla.tar.gz https://github.com/leenooks/phpLDAPadmin/archive/refs/tags/${VERSION}.tar.gz`; `tar xzf /tmp/pla.tar.gz -C /app/www --strip-components=1`; `cd /app/www && COMPOSER_HOME=/tmp/composer composer install --no-dev --optimize-autoloader`. If the repo ships built front-end assets (UNVERIFIED) no node is needed; otherwise add a node build stage.
4. Replace writable Laravel dirs with symlinks as `apps/bookstack` does (it links into `/config`; here the targets are /tmp or /config): `storage/framework/sessions`, `storage/framework/cache`, `storage/framework/views`, `storage/logs`, `bootstrap/cache` -> `/tmp/pla/...` (ephemeral) and `.env` -> `/tmp/pla/.env` or env-only.
5. Licenses: `cp /app/www/LICENSE /usr/share/licenses/phpldapadmin/`.
6. nginx and php-fpm configs from `etc/` copied via `COPY . /` (pid, logs, temp paths in /tmp, listen 8080, fpm socket in /tmp).
7. `ENV HOME=/config COMPOSER_HOME=/tmp/composer`.
8. `chown -R apps:apps /app`; `USER apps`; `COPY --chmod=0755 . /`; `EXPOSE 8080`; `VOLUME /config`.

## 6. settings.yaml

Header, `schema_version: 1`, `upstream_env_url: "https://github.com/leenooks/phpLDAPadmin/"`.
- ports: `8080` tcp required false. (Draft's 80/443 dropped: non-root cannot bind 80 and TLS is delegated to a proxy per upstream.)
- env: `LDAP_HOST` default "" required false (start.sh warns; image must start without it); `LDAP_USERNAME`, `LDAP_PASSWORD` default "" required false; `APP_KEY` default "" (generated by start.sh into /config when unset); `APP_TIMEZONE` default `UTC`; `LDAP_CACHE` default `false`; `CACHE_DRIVER` default `file`; `TZ` default `Etc/UTC`.
- volumes: `/config` required true.
- dependencies: none (needs an external LDAP server; not a ContainerForge app).

## 7. start.sh

1. `mkdir -p /config/pla /tmp/pla/{sessions,cache,views,logs,bootstrap}`.
2. If `APP_KEY` unset: read `/config/pla/app.key`; if missing, generate with `php /app/www/artisan key:generate --show` and write it (chmod 600). Export it so the key persists across restarts (upstream regenerates on each start otherwise).
3. Export `LDAP_HOST` etc. (Laravel reads real env); warn if `LDAP_HOST` empty.
4. Start php-fpm in background (config in /etc), then `exec nginx -g 'daemon off;'`. Bind 0.0.0.0:8080. No writes to /app.
Idempotent: key file written only when missing.

## 9. Rootless and read-only-rootfs adaptations

- Draft: osixia image ran root with writable rootfs; PLA v2 upstream already runs non-root on 8080, so `USER apps` matches.
- Write paths: Laravel `storage/*`, `bootstrap/cache` (-> /tmp symlinks), nginx pid/temp/logs and php-fpm socket/pid (-> /tmp via config), composer cache (/tmp/composer), generated key (/config/pla/app.key).
- Sessions in /tmp are lost on restart; upstream mounts them as volumes. Decide whether to put sessions in /config/pla/sessions (open question).

## 10. Risks, caveats and open questions

- Draft is based on PLA 1.x/osixia (GPL, s6, slow maintenance); this plan deliberately targets v2 and the README's own image, which changes the config model (env vars, no `config.php`).
- License conflict (GPL-2.0 vs MIT) must be resolved before PR.
- PHP ^8.5 requirement: bookstack proves php8.5 packages exist on this base; confirm `php8.5-ldap`.
- Upstream uses FrankenPHP; our nginx+fpm layout is a deviation and untested against PLA's routing (`try_files` to `public/index.php`).
- Needs an external LDAP server; TLS to LDAP (LDAPS cert trust) not planned.
- No arm64 blocker (PHP).

## 11. Build and test steps

```sh
cd apps/phpldapadmin
docker buildx bake --print
docker buildx bake --set image-local.platform=linux/amd64 image-local
docker run --rm -d --name phpldapadmin-probe --read-only --tmpfs /tmp \
  -v phpldapadmin-probe-config:/config phpldapadmin:2.3.13
docker logs -f phpldapadmin-probe
curl -i http://localhost:8080/   # with -p 8080:8080
forgetool containers test --image phpldapadmin:2.3.13 --config ./apps/phpldapadmin/container-test.yaml
docker rm -f phpldapadmin-probe; docker volume rm phpldapadmin-probe-config
```
Expected: nginx and php-fpm running, port 8080 open, no PHP fatal errors in logs; second run with `-e LDAP_HOST=<host>` reaches the login page.
