# chowdown.io (project website)

Source URL(s) + fetch date:
- https://chowdown.io (fetched 2026-11-26)

## What it is
A recipe website listing dishes (e.g. banana bread, green chile stew, mongolian beef), with navigation for Recipes, Search and Books, plus an "Updates" link that points to https://github.com/clarklab/chowdown.

## Install/self-hosting
Not described on the site. Build and serve instructions are in the source repo (see github-clarklab-chowdown.md).

## Gotchas
- `_config.yml` sets `baseurl`/url to `https://chowdown.io` (per plan.md). Building the site elsewhere may leave absolute links to chowdown.io; plan.md recommends checking the output.
