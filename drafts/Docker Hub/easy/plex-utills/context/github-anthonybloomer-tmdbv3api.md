## What it is
- Lightweight Python wrapper for The Movie Database (TMDb) API: movies, TV, cast, posters, fan art, search, discovery, account/watchlist, pagination, in-memory response caching.

## Install
- `pip install tmdbv3api` (PyPI name `tmdbv3api`). The upstream Dockerfile installs from git (`pip install git+https://github.com/AnthonyBloomer/tmdbv3api.git`).
