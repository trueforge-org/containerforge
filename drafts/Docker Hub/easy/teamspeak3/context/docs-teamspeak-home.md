# teamspeak.com home page (product overview)

**Source URL(s)** (fetched 2026-11-26): https://www.teamspeak.com/en

## What it is
Product overview for TeamSpeak (voice communication, clients for desktop, Android, iOS; TeamSpeak 6 is the current client generation).

## Self-hosted server facts
- Self-hosting is aimed at people who own their hardware.
- Licensing section exists at /en/features/licensing/ (not fetched; pricing/terms not on this page).
- Admins get permission system, server groups, channels, ban/kick tools; AES-based encryption at server or channel level.
- Hosted alternative: "TS Official Communities"; third-party hosts via "Find a Host".

## Not covered
Server download specifics, system requirements, licence tiers, slot limits, costs. See the downloads page and licensing page.
