Source URL(s) + fetch date:

## Facts
- Free, open-source home automation, "lightweight, stable, and privacy-first", runs locally with no cloud account.
- Platforms: Linux, Windows, Raspberry Pi (down to Pi Zero), Docker. HTML5 web UI.
- Install: Linux/RPi one-liner `curl -sSL install.domoticz.com | sudo bash`; Windows installer; downloads page https://www.domoticz.com/downloads/.
- Scripting: dzVents, Blockly, Lua; Python also listed.
- Links: wiki https://wiki.domoticz.com/, forum https://forum.domoticz.com/, GitHub https://github.com/domoticz/domoticz.
