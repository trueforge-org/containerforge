## Facts
- Describes Domoticz as "very light weight home automation system", open source and free.
- Default login on first install: username/password `admin/domoticz` (wiki). The README says the setup wizard creates the admin account instead, and the Docker env `DOMOTICZ_ADMIN_PASSWORD` provisions it. These two statements are not reconciled by the sources here.
- Install sections: Raspberry Pi, Windows, Linux, Docker, Synology NAS (the Docker page is linked but not fetched).
- Index includes "Build Domoticz from source", "Native HTTPS / SSL support", "Native secure access with Lets Encrypt", "Moving Log and Temporary Files To a RAM Drive". No port numbers or userdata paths on the home page.
