## What it is
User documentation landing page for TagSpaces: privacy-focused, open-source, cross-platform file organiser; tags and descriptions on the local file system; "no cloud accounts, no databases, no vendor lock-in".

## Install/web/Docker information
- No install steps on this page; next page is "Installing TagSpaces" (/installation/).
- No Docker instructions.
- TagSpaces Pro Web: self-hosted web app for files on S3-compatible object storage (AWS SDK). No setup steps here.
- Editions named: Lite (free desktop: Windows, macOS, Linux), Pro, Custom (enterprise), Web Clipper (browser extension).
- Live demo: demo.tagspaces.com.

## Ports
None mentioned.

## Storage
Local files; tags in filenames or sidecar files. Can sit on sync tools (Dropbox, Google Drive, Nextcloud, Syncthing).
