## What it is
Web-based configurator for printable drive caddy labels for homelab servers. Users add one or more labels, then print the page at its original size (Chrome: enable "Background Graphics" in print settings).

## Configurator options
- Vendor (three logo images), form factor (2.5" or 3.5"), generation, interface type, interface speed, disk speed, disk type, capacity, serial/part number, number of disks.
- Buttons: Start, Print Page, Reset, Add More / Add Disk(s).
