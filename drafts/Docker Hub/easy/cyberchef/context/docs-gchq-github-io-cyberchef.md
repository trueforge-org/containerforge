## What it is
Browser-only web app for analysing and decoding data, with hundreds of operations; recipes can be shared.

## Runtime
- "Entirely within your browser with no server-side component".
- Exceptions that contact outside services: "Show on map" (wikimedia.org map tiles), "DNS over HTTPS" (Google or Cloudflare), and "HTTP request" (any user-entered URL).

## Install/usage options
- Live version in browser.
- Standalone ZIP download: runs locally or on any web server, no configuration needed, does not self-update.
