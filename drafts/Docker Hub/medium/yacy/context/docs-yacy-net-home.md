## Home (yacy.net)
- YaCy is "free software for your own search engine": local search, organisation portals, and a decentralised P2P web index.
- Modes: P2P (shared index among independent peers), search portal (own index and crawl), intranet search.
- Gathers no personal data; no built-in phone-home. Website uses no cookies.
- Brand owned by a private company; the software is run as a non-profit and offers consulting.
- License: not named on the page ("free software").
- Links: download (/download_installation/), docs (/docs/), FAQ, demo, source code (GitHub), forum, stats, YouTube tutorials. No Docker instructions on the home page.
