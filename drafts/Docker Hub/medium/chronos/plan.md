## 4. Dockerfile

1. Stage `ui` (ubuntu base, `USER root`, `HOME=/tmp`): download and extract the tag tarball to `/build/chronos`; `cd chronos-ui && yarn install && NODE_OPTIONS=--openssl-legacy-provider yarn build` (webpack 4 / vue-cli 4.3 need the legacy OpenSSL provider on modern Node; whether Node 26 still supports it is UNVERIFIED, otherwise fall back to a pinned older Node via a `node` image stage). Caches: `YARN_CACHE_FOLDER=/tmp/yarn`.
2. Final stage `FROM <python base>`, `ARG VERSION`, `USER root`.
3. `ENV CHRONOS_PATH=/config PYTHONPATH=/app/chronos HOME=/config PIP_CACHE_DIR=/tmp/pip`.
4. Download the tarball again (or `COPY --from=ui /build/chronos /app/chronos`) and keep `/app/chronos/chronos-ui/dist`; delete `chronos-ui/node_modules`, `tests`, `.git*`.
5. Dependencies into the base venv (pattern of `apps/changedetection`): `/app/venv/bin/pip install` a relaxed copy of `requirements.txt`: drop dev/test-only pins (`black`, `pytest`, `mock`, `typed-ast`, `pluggy`, `py`), drop `-e .` (replaced by `PYTHONPATH`), and loosen the rest to unpinned or `>=` so wheels exist for Python 3.15 (`gevent`, `greenlet`, `cryptography`, `pendulum`, `Twisted`, `cffi`). Ship the relaxed file as `defaults`-independent build input generated by `sed`, not an edit of upstream sources. apt build deps if sdists are needed: `build-essential libffi-dev libssl-dev` (installed and purged in the same RUN). `freetds-dev`/`pymssql` from the upstream Dockerfile are NOT in `requirements.txt`; skip them (UNVERIFIED whether user scripts expect pymssql).
6. License: `cp /app/chronos/LICENSE /usr/share/licenses/chronos/LICENSE`.
7. `chown -R root:root /app && chmod -R 755 /app`, `EXPOSE 5000`, `VOLUME /config`.
8. `COPY --chmod=0755 . /`.
9. Final line `USER apps`.

## 5. docker-bake.hcl

```hcl
target "docker-metadata-action" {}

variable "APP" {
  default = "chronos"
}

variable "VERSION" {
  // renovate: datasource=github-tags depName=simse/chronos versioning=loose
  default = "0.2"
}

variable "LICENSE" {
  default = "MIT"
}

variable "SOURCE" {
  default = "https://github.com/simse/chronos"
}

group "default" {
  targets = ["image-local"]
}

target "image" {
  inherits = ["docker-metadata-action"]
  args = {
    VERSION = "${VERSION}"
  }
  labels = {
    "org.opencontainers.image.source" = "${SOURCE}"
    "org.opencontainers.image.licenses" = "${LICENSE}"
  }
}

target "image-local" {
  inherits = ["image"]
  output = ["type=docker"]
  tags = ["${APP}:${VERSION}"]
}

target "image-all" {
  inherits = ["image"]
  platforms = [
    "linux/amd64",
    "linux/arm64"
  ]
}
```
Validate with `docker buildx bake --print` from `apps/chronos/`. Dockerfile `ARG VERSION` must receive exactly this value (no extra defaults).

## 7. start.sh

1. `export CHRONOS_PATH="${CHRONOS_PATH:-/config}"` (required by the app; default makes the no-env test pass).
2. `mkdir -p "$CHRONOS_PATH/logs" "$CHRONOS_PATH/scripts"` (idempotent; db is created by the app).
3. `export PIP_CACHE_DIR=/tmp/pip TMPDIR=/tmp PYTHONDONTWRITEBYTECODE=1`.
4. `cd /app/chronos` (alembic `script_location = alembic` and `alembic.ini` are resolved from cwd by `migrate()`).
5. `exec /app/venv/bin/python chronos.py` (Twisted binds all interfaces on 5000).

## 9. Rootless and read-only-rootfs adaptations

| Upstream write | Remap |
|---|---|
| `/chronos` volume (draft: chart PVC at `/chronos`) | `CHRONOS_PATH=/config` (db, logs, scripts) |
| Per-script virtualenvs `scripts/<uid>/.venv` | stay in `/config/scripts` (persistent by design); created by the python base's `python -m venv`; `ensurepip` availability UNVERIFIED |
| pip cache inside script venvs | `PIP_CACHE_DIR=/tmp/pip` |
| `__pycache__` | `PYTHONDONTWRITEBYTECODE=1` |
| Timezone symlink in upstream Dockerfile (`ln -snf ... /etc/localtime`) | Not done; use `TZ` env |

Draft security expectation (root, writable rootfs, `/chronos` PVC) is replaced by UID 568, read-only rootfs and `/config`. Not privileged.

## 10. Risks, caveats and open questions

- HIGH: upstream is archived (2023) and the dependency pins are for Python 3.7. Flask 1.1, Jinja2 2.11, Twisted 20.3, gevent 20.5, `maya`/`pendulum` 2.x may not import on Python 3.15, so loosening pins may still need source patches. If installs or imports fail within the 10-round limit, record as unfixable or target an older Python through `uv`.
- vue-cli 4.3 / webpack 4 build on Node 26 may fail (`ERR_OSSL_EVP_UNSUPPORTED`, node-sass-era packages); fallback is an older Node stage.
- README: "zero security against unauthorised access": the UI lets any visitor execute Python on the server. Never expose publicly; consider documenting this.
- User scripts run via pip in per-script venvs and need outbound network.
- Chart persisted `/chronos`; migrating existing data means mounting it at `/config`.
- No release artifacts or checksums; tag tarball only.

## 11. Build and test steps

Run per `build-test-protocol.instructions.md`, one app only, max 10 rounds:

```sh
cd apps/chronos
docker buildx bake --print
docker buildx bake --set image-local.platform=linux/amd64 image-local
docker volume create chronos-probe-config
docker run --rm -d --name chronos-probe --read-only --tmpfs /tmp \
  -v chronos-probe-config:/config chronos:<VERSION>
docker logs -f chronos-probe        # expect: `Starting Chronos: ...`, `API server started`, and port 5000 open
docker rm -f chronos-probe; docker volume rm chronos-probe-config
forgetool containers test --image chronos:<VERSION> --config ./apps/chronos/container-test.yaml
```

Always start from an empty `/config` volume and check that the container is still running, with no fatal errors or repeated stack traces. Attempt arm64 only if the amd64 loop is green or the failure is arm64-specific.
