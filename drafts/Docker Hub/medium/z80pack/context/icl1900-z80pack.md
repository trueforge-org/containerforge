## What it is
- Project site for z80pack (Udo Munk). Same description as upstream README: Zilog Z80 and Intel 8080 cross development package for UNIX and Windows, BSD-style license ("distributed with all sources under a BSD style license").

## Components listed
- z80sim: generic Z80/8080 CPU emulation with ICE-like UI.
- z80asm: Z80 cross assembler.
- cpmsim: CP/M 1, 2, 3 and MP/M 2 emulation, bootable OS disk images included.
- altairsim: Altair 8800 emulation.
