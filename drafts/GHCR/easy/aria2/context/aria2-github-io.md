# aria2.github.io (homepage + manual)
Source URL(s): https://aria2.github.io (fetched), https://aria2.github.io/manual/en/html (fetched as aria2c.html manual)

## Homepage
- Download version 1.37.0 (source distribution and binaries for OS X, Windows, Android)
- Protocols: HTTP/HTTPS, FTP, SFTP, BitTorrent, Metalink
- Manipulated via built-in JSON-RPC and XML-RPC

## Manual (aria2c 1.37.0)
- Sections: Basic, HTTP/FTP/SFTP, BitTorrent/Metalink, RPC, Advanced, Event Hook, Exit Status, Environment, Files (aria2.conf, dht.dat, netrc, control file, input file)
- RPC interface: JSON-RPC and XML-RPC; methods include aria2.addUri, aria2.tellStatus, aria2.getVersion, system.multicall
- RPC authorization via "secret token" (`--rpc-secret`)
- JSON-RPC over HTTP GET and WebSocket supported
- Option tables not extracted in full here (only the TOC was in the fetched text)
