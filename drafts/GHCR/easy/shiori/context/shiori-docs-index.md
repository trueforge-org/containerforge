## What it is
- Simple bookmarks manager in Go, Pocket clone; CLI and web app.
- Features: add/edit/delete/search, Netscape bookmark import/export, Pocket import, offline page archiving.
- DB support: SQLite, PostgreSQL, MySQL (MariaDB per README).
