# Upstream docs: Komga introduction

Source URL(s) + date: https://komga.org/docs/introduction (fetched 2026-11-27). Main site https://komga.org not fetched (docs page sufficient).

## What it is
- Media server for comics, mangas, BDs, magazines and eBooks.
- Workflow: install on computer/NAS, add libraries by content type, use web UI or compatible client.

## Media types
- CBZ and CBR (comic archives), EPUB, PDF.

## Platforms
- "Any system that can run Java or Docker": Windows, macOS, Linux, NAS (QNAP, Synology, etc.).
