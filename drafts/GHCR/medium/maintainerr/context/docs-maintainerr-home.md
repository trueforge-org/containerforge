## Website (maintainerr.info)
- "A free, open-source, self-hosted app" that finds and removes unwatched or unwanted movies and TV shows from Plex, Jellyfin and Emby using user-defined rules.
- Rule data sources: Plex, Jellyfin, Emby, Radarr, Sonarr, Sportarr, Tautulli, Streamystats, Tracearr, Seerr.
- Actions: delete files, unmonitor or change quality profile in *arr, clear Seerr requests, remove files from qBittorrent.
- Features: deletion calendar, storage insights, "Leaving soon" poster overlays, community rule presets, notifications (Discord, Telegram, Slack, email), switching media servers with rule migration.
- License: "open source", not named on the page (MIT per the repo, see github-maintainerr-maintainerr.md).
- Docker Hub: https://hub.docker.com/r/maintainerr/maintainerr.
