# Audiobookshelf site and docs (www.audiobookshelf.org)

**Source URL(s):** https://www.audiobookshelf.org (home), https://www.audiobookshelf.org/docs (intro), https://www.audiobookshelf.org/docs/installation (follow-up; fetched 2026-11-27)

## What it is
- Open-source self-hosted media server for audiobooks and podcasts.
- Features (docs intro): companion Android and iOS app with offline listening (beta); multi-user with custom permissions; per-user progress synced across devices; metadata and cover lookup from several providers; chapter editor; embed metadata and merge audio files to m4b; podcast search and auto-download; RSS feeds; backups with scheduling.

## Docs sections
- Introduction, Installation, Libraries, Mobile Apps, Server Management, Community (FAQ), Contributing, Showcase.

## Gotchas
- `/docs/installation` is JS-rendered; no install or env content was retrievable from the static HTML. Install facts come from the Dockerfile and chart instead.
