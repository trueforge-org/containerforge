## Workload
- type: DaemonSet, name `main`. hostNetwork true, hostPID true, priorityClassName system-node-critical, tolerations Exists.
- Main container: privileged true, runAsUser 0, runAsGroup 0.
- Resources: requests cpu 100m / mem 50Mi; limits cpu 200m / mem 500Mi.
- Env: MULTUS_NODE_NAME from fieldRef (spec.nodeName).
- Probes (all exec): liveness, readiness, startup each run `sh -c 'cat <cniconf>/00-multus.conf*'`.
- Init containers: talos-plugin-installer (crane export of talosCniImage), multus-plugin-installer, and dhcp-daemon (talos integration, optional).
