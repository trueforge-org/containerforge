## What it is
- QDirStat: Qt-based directory statistics; KDirStat without KDE. Author Stefan Hundhammer.
- Targets: Linux, BSD, Unix-like, macOS. X11 desktop needed.
- License: GPL v2.
- README "Updated 2026-11-26".

## Features (relevant)
- Tree view + treemap, multi-selection, cleanup actions, package-manager views (dpkg/rpm), file-age and per-type stats.
- Qt6 based; no KDE libs.

## Gotchas
- Upstream source tarball is used by the image (`archive/2.0.tar.gz`, from Dockerfile).
