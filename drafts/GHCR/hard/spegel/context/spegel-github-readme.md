# spegel-org/spegel README
Source URL: https://raw.githubusercontent.com/spegel-org/spegel/main/README.md (fetched 2026-11-27)

- Spegel = stateless cluster-local OCI registry mirror (Swedish: mirror). Developed initially at Xenit AB.
- Locally caches images from external registries with no explicit configuration; falls back on cache during registry downtime; avoids rate limits.
- Project has no guaranteed support (best effort; home lab focus).
- Getting started docs: https://spegel.dev/docs/getting-started/ (not fetched)
