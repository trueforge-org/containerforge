# Upstream website and license: sqlitebrowser
Sources: https://sqlitebrowser.org (fetched 2026-11-27); https://raw.githubusercontent.com/sqlitebrowser/sqlitebrowser/master/LICENSE (fetched 2026-11-27)

## What it is
- DB Browser for SQLite (DB4S): open source visual tool to create, search, edit SQLite or SQLCipher DB files
- Runs on Windows, macOS, most Linux/Unix

## Features
- Create/compact DBs; create/modify/delete tables and indexes; browse/edit/add/delete records
- Sort/search; import/export text, CSV, SQL dump; run SQL queries; SQL log; simple plots; SQLCipher encryption add/change/remove
