## What it is
- Self-hosted audiobook streaming server, successor to original Booksonic; built on Airsonic (Subsonic/Libresonic lineage)
- Java-based; runs on Windows, Mac, Linux, Unix; streams via Subsonic API
- Transcoder plugins for WMA, FLAC, APE, Musepack, WavPack, Shorten; max bitrate caps
